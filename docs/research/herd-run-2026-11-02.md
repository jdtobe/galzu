# Overnight herd run, 2026-11-02

One unattended run, recorded because the PoC's actual question — *does a herd feel
useful rather than like isolated chatbots?* — has had no evidence until now.
Short answer: the machinery works, the herd drifted into the wrong domain, and
the plan loop thrashed.

## Setup

| | |
|---|---|
| Agents | Ada (leader, `qwen3.5-9b-uncensored:q4-k-m`), Beau and Cy (helpers, `lfm3-1.7b-uncensored:q6-k`) |
| Concurrency | 2 |
| Thinking | off |
| Human | **none** — no messages, no approvals, no plan decisions |
| Goal | *Agree on the single most valuable next feature for Galzu, the herd platform you are running inside… compare three candidates… produce a plan with steps, definition of done and acceptance criteria.* |

The goal was deliberately scoped to what agents can actually do: they cannot
read files or reach the network, so the output is a decision and a plan, not
code.

## What happened

Roughly six minutes of wall clock, then paused:

- **36 messages**, 34 public and 2 direct.
- **28 of them were plan proposals**, across **10 versions**.
- **6 vote-related messages**; votes were called, tallied and closed.
- All three agents stayed `ready`; no retries, no errors.

So the new machinery does what it was built to do: proposals open, ballots
count, votes close, plans version, and closing messages are attributed to the
host rather than to a model.

## Finding 1 — the herd picked the wrong product

The conversation is about **livestock disease surveillance**. In 36 messages the
words *herd health* appear 26 times, *anomaly* 28, *outbreak* 20, *livestock* 3,
*veterinary* 2. The chosen feature is "Real-time Anomaly Detection Alerts" for
"herd health" with a staged rollout and a 12-month time-series of vitals and
movement.

Galzu is a platform for running AI agents. Nothing in the run went near that.

**Cause:** the agents cannot read the repository and were given no description
of the product beyond one sentence containing the word *herd*. With no other
signal, "herd" resolved to animals. This is not a model failure so much as a
**context failure**: the preamble carries the goal and the culture, and nothing
about the domain.

**Fix:** a session needs a **brief** — a few lines of product context supplied at
creation and rendered in the preamble, next to the goal. Cheap, and it would
have prevented all 36 messages of drift.

## Finding 2 — plan proposals thrash

Ten plan versions in six minutes. The rule "one pending plan at a time, a new
proposal supersedes the old" turned into a loop: each agent, seeing a pending
plan it had not written, proposed its own, which superseded the previous one,
which prompted another. Nothing told them to stop, and there was no human to
approve.

The prompt now says: *do not propose another while this one waits*. That is a
patch on a design gap — a pending plan should be a stable waiting state, and the
herd treated "pending" as "unaddressed".

**Fix:** the prompt guard above, plus a real decision on whether a pending plan
should suppress proposals for a period, or whether agents should be told who is
waiting on whom.

## Finding 3 — the fabric was not used

The `available` action did not exist during this run, so agents had no way to ask
for work. They also never used `help`. Every turn went to a public message or a
plan proposal: the herd talked *at* the group, not to each other.

That is consistent with the PoC question and not yet an answer to it. A run where
agents negotiate, volunteer and assign work is the next comparison.

## What was changed as a result

- The pending-plan prompt now forbids re-proposing while a plan waits.
- `available` was added after this run, with escalation to the leader, so the
  next run can exercise the fabric.

Not yet changed, and worth doing next:

- A **brief** field on the session, carried in the preamble. Without it, every
  run will reinvent the product from the goal's nouns.
- A plan decision *by the human* during the run. This run had none, which is
  realistic for an unattended night but makes the plan loop a poor test of
  approval.

## Caveats

One run. Small, uncensored models. No thinking. No human in the loop. The 9B
leader and the 1.7B helpers have different vocabularies, and the leader wrote
most of the plans. None of this is a benchmark; it is a first observation, and
the domain drift is the part worth trusting because it is unambiguous.
