# Briefed herd run, 2026-11-03

The second unattended run, and the first with a brief, findings, and a human
approving a plan. Short answer: the brief fixed the domain drift completely, and
the fabric is used, but the herd still decides poorly. One model may be enough
for the same goal; the solo control is recorded below.

## Setup

| | |
|---|---|
| Agents | Ada (leader, `qwen3.5-9b-uncensored:q4-k-m`), Beau and Cy (helpers, `lfm3-1.7b-uncensored:q6-k`) |
| Concurrency | 2 |
| Thinking | off |
| Brief | Galzu is a platform for a herd of AI agents; "herd" never means animals; Go, vanilla JS, SQLite; lists existing features and says agents cannot read files or reach the network |
| Goal | Choose the next feature; compare three candidates; publish two findings with evidence; endorse or challenge someone else's; propose one plan |
| Human | one automated approval of the first stable pending plan, with a note |
| Duration | about six minutes, then paused after three minutes of quiet |

## What happened

- **17 messages**: 10 ordinary, 5 findings, 1 direct, 1 endorsement.
- **5 findings**, 3 with evidence, **1 position** in total.
- **4 proposals**, all still open, with **one vote** cast (a leader vote against
  sentiment tagging).
- **2 plans**: v1 superseded, v2 approved by the human.
- **Zero** occurrences of *livestock*, *cattle*, *veterinary*, *herd health* or
  *outbreak*. The previous run had 26, 28 and 20 occurrences of the first, third
  and fifth, and designed animal surveillance.

The run is not a benchmark. It is one short observation with small uncensored
models, and the interesting parts are the failures.

## Finding 1 — the brief worked

The brief is the only change that touched the domain, and the domain drift
disappeared. Every finding and both plans were about the agent platform. The
ideas were ordinary and incremental (a searchable heritage archive, sentiment
tags on messages, a task board), but they were *in the right product*.

The brief also seeds: it lists existing features, and the helpers spent their
turns recombining that list. Context prevents a wrong world; it does not by
itself produce a good idea.

## Finding 2 — the fabric is used, but thin

The new `finding` and `endorse` actions were used without instruction beyond the
goal, and findings appeared in the prompt. But the herd published claims more
readily than it examined them:

- 5 claims, 3 with evidence, **1 position**.
- No revision, no challenge with opposing evidence.
- The only cross-check was a **direct message from the leader** challenging a
  helper's endorsement. It was articulate and it did not change the outcome.

So the social fabric is no longer missing; it is underused. A finding with no
positions is a broadcast, not shared knowledge.

The harness now nudges when no finding has a position, and lets a sole agent
continue its own thread. Neither was in the binary that produced this run.

## Finding 3 — the plan contradicted the debate

The leader argued for an **agent research task board** and voted **no** on
sentiment tagging. A helper proposed **sentiment tagging**; that plan was
approved. Nothing in the plan said which decision it implemented, and no vote had
passed. The plan won by being on the table at the right moment.

This is the most useful product finding: the herd had the material for a
decision and skipped the decision. The plan artifact had no provenance.

The harness now accepts an optional `proposal:<id>` on a plan and refuses an
open or failed proposal. The plan panel shows the reference and warns that
approval does not answer open questions. That does not force the herd to decide,
but it makes the gap visible instead of invisible.

## Finding 4 — questions outnumber decisions

Four proposals opened; one ballot was cast; none closed before the run ended.
The ten-minute close never arrived because the session was paused. This is not a
timer bug: pause stops scheduling, and the vote would settle on resume. It is a
pacing result. The herd proposes faster than it votes, and an operator watching a
six-minute run sees a wall of open questions.

## Comparison

| | Run 1 (no brief) | Run 2 (brief, partial) | Run 3 (brief + findings) |
|---|---|---|---|
| Messages | 36 | 22 | 17 |
| Plan versions | 10 | 13 | 2 |
| Findings | — | — | 5 |
| Questions | 6 vote messages | — | 4, none closed |
| Human decisions | none | one plan approved | one plan approved |
| Domain | livestock surveillance | product | product |

Run 2 used a brief but no findings and was interrupted by a server restart after
22 messages and 13 plan versions. Run 3 replaced plan thrash with a small amount
of evidence work, which is the direction the fabric was meant to move.

## Solo control

The same goal and brief were given to one `qwen3.5-9b-uncensored:q4-k-m` agent
with the same harness and human approval.

It produced **7 messages**: a proposal comparing three infrastructure candidates
(semantic context, a sandboxed tool executor, a peer-review pipeline for
findings), a vote for the review pipeline, a closed vote, a plan for that
pipeline, and the human approval. It chose the feature that extended the
product's own findings loop, and it explained why the other candidates were
worse.

The solo run did **not** publish findings, although the goal asked for two. It
also needed two turns of human-shaped nudging: the harness at the time had no
single-agent continuation, so the agent answered the goal once and stopped until
a host message arrived. The code now lets a sole agent continue on its own.

The 9B model took about 107 seconds on one turn and over two minutes on another.
The herd felt faster because the helpers inferred in parallel, and its throughput
was real; its decision quality was not.

### What the comparison says

One small model, given the brief and the same goal, produced a more coherent
decision than the three-agent herd: one proposal, one vote, one plan, one
approval, and a feature that builds on what exists. The herd produced more
artifacts, more candidate ideas, and a plan its own leader had argued against.

That is one run, and it is not a verdict on herds. It is a verdict on **this**
herd: adding two 1.7B models did not add evidence or challenge; it added turns.
A useful next experiment is not more agents but agents with different material —
a stronger model, a different source of context, or a role that requires
verification — and a goal that makes disagreement worth something.

## Later attempts

Two more runs were started after this one. A mixed-model provenance run reached
five messages and one finding before the models stalled on repeated inference,
and a homogeneous 9B herd reached four messages and three findings before the
same. Neither produced a plan, so neither is evidence about provenance. The local
model server was swapping between models under memory pressure; that is a
scheduling limit of the deployment, not a harness failure. The mixed run was
stopped by hand; the homogeneous run was stopped after its queue made no progress
for several minutes.

## Changed as a result

- Plans may cite a passed proposal, and the gap is shown when they do not.
- An approved plan is called the working plan and replacement needs a specific
  defect; the prompt no longer treats approval as another round of input.
- A done plan can be closed by the human, and the next increment can begin.
- Findings with no positions trigger one prompt nudge, and a second agent's
  position labels a finding peer reviewed.
- An agent can ask one peer to review a finding; a revision, evidence, position
  or withdrawal answers the request. There is no deadline and no gate.
- An agent can recall matching findings by claim or evidence; the answer is a
  private host message with the tally and evidence.
- The operator can mark a finding verified, separately from agreement; the mark
  is shown to the herd and cleared on withdrawal.
- A finding can be withdrawn by its author or the leader without deleting its
  evidence or positions.
- A one-agent session continues its own thread, bounded, instead of stalling.
- A session can opt into idle reflection: one agent is woken after the whole
  herd has been quiet. It is off by default.
- The brief can carry selected reference files read in the browser, and is 16 KiB.
- A cross-session Findings view, Markdown export, and search over briefs and
  findings make the record usable outside the session that produced it.

## Caveats

One run. Small models, no thinking, an automated approval rather than a human
reading every plan, and a pause at three minutes of quiet. The domain result is
unambiguous; the decision-quality result is an observation, not a measurement.
